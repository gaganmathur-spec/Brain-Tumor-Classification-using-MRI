# 🧠 Brain Tumor Classification using MRI

🧠 A **Machine Learning project** that classifies **brain MRI images** using **HOG feature extraction** and a **Decision Tree Classifier**.

🎯 **Objective:** Predict the tumor category from MRI images using Machine Learning.

✨ **Key Features:**

* 🧠 MRI image classification
* 🔍 HOG feature extraction
* 🌳 Decision Tree Classifier
* 🧹 Image preprocessing
* 📊 Model evaluation
* 🌐 Streamlit web application

🛠️ **Built With:** 🐍 Python • 🖼️ OpenCV • 🤖 Scikit-learn • 🌐 Streamlit
