🧠 Brain Tumor Classification using MRI

A Machine Learning-based image classification application that analyzes brain MRI scans using HOG (Histogram of Oriented Gradients) feature extraction and a Decision Tree Classifier to predict tumor categories.

🎯 Objective

To develop an image classification system that processes brain MRI images, extracts meaningful visual patterns, and predicts tumor categories using image processing and Machine Learning techniques.

✨ Key Features

- 🧠 Brain MRI Image Classification
- 🔍 HOG (Histogram of Oriented Gradients) Feature Extraction
- 🌳 Decision Tree Classification
- 🧹 Image Preprocessing and Feature Engineering
- 📊 Model Performance Evaluation
- ⚡ Real-Time MRI Image Prediction
- 🌐 Interactive Streamlit Web Application

🛠️ Tech Stack

- Programming Language: Python
- Image Processing: OpenCV
- Feature Extraction: HOG
- Machine Learning: Scikit-learn
- Web Framework: Streamlit
- Model Development: NumPy, Pandas

🚀 Application

The application provides an interactive interface where users can upload brain MRI images and receive predicted tumor categories using a trained Machine Learning model.

⚙️ Project Workflow

1. Upload brain MRI image.
2. Perform image preprocessing.
3. Extract image features using HOG.
4. Pass extracted features to the trained Decision Tree Classifier.
5. Generate and display the predicted category.

💡 Key Learning Outcomes

- Understanding image classification techniques.
- Implementing HOG-based feature extraction.
- Applying Decision Tree algorithms to image data.
- Building an end-to-end Machine Learning application.
- Deploying an ML application using Streamlit.
