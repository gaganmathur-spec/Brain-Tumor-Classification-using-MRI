🧠 Brain Tumor Classification using MRI

A Machine Learning-based application that classifies brain MRI images using HOG (Histogram of Oriented Gradients) feature extraction and a Decision Tree Classifier.

🎯 Objective

To develop an image classification system that analyzes brain MRI scans, extracts important visual features, and predicts tumor categories using image processing and Machine Learning techniques.

✨ Key Features

- 🧠 Brain MRI Image Classification
- 🔍 HOG (Histogram of Oriented Gradients) Feature Extraction
- 🌳 Decision Tree Classification
- 🧹 Image Preprocessing and Feature Extraction
- 📊 Model Performance Evaluation
- ⚡ Real-Time MRI Image Prediction
- 🌐 Interactive Streamlit Web Application

🛠️ Tech Stack

- Programming: Python
- Image Processing: OpenCV
- Feature Extraction: HOG
- Machine Learning: Scikit-learn
- Web Framework: Streamlit

🚀 Application

An interactive web application that allows users to upload brain MRI images and receive predicted tumor categories using a trained Machine Learning model.
