# 🧠 Brain Tumor Classification using MRI
🧠 Brain Tumor Classification using Machine Learning & Streamlit A Machine Learning project that classifies brain MRI images using **HOG (Histogram of Oriented Gradients) feature extraction** and a **Decision Tree Classifier**. The project includes image preprocessing, model training, feature extraction, confidence-based predictions, and an interactive **Streamlit web application** for real-time brain tumor classification.
