# 🧠 Brain Tumor Classification using MRI
🧠Brain Tumor Classification using Machine Learning & Streamlit, A Machine Learning project designed to classify **brain MRI images** using **HOG (Histogram of Oriented Gradients)** for feature extraction and a **Decision Tree Classifier** for prediction. The project includes image preprocessing, model training, feature extraction, confidence-based predictions, and an interactive **Streamlit web application** for real-time tumor classification.
