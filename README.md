🧠 Brain Tumor Classification using MRI

🧠 Brain Tumor Classification is a Machine Learning project that classifies brain MRI images using HOG (Histogram of Oriented Gradients) for feature extraction and a Decision Tree Classifier for prediction.

🎯 Objective: Develop an image classification system that can analyze MRI scans and predict the tumor category using Machine Learning.

✨ Key Features:

- 🧠 Brain MRI image classification
- 🔍 HOG-based feature extraction
- 🌳 Decision Tree Classifier
- 🧹 Image preprocessing
- 📈 Model training and evaluation
- 🎯 Confidence-based predictions
- 🌐 Interactive Streamlit application

🛠️ Built With: 🐍 Python • 🖼️ OpenCV • 🤖 Scikit-learn • 🌐 Streamlit
